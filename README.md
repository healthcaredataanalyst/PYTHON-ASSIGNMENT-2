## Data Structures - List, Dictionary, Set & Conditional Statements

### Project Overview

This assignment demonstrates the basic concepts of Python data structures and conditional statements.

The assignment covers List, Dictionary, Set, and IF-ELIF-ELSE statements.

## Topics Covered

### 1. List
- Creating lists
- append()
- insert()
- remove()
- pop()
- extend()
- sort()
- max(), min(), and sum()
- List indexing and slicing

### 2. Dictionary
- Creating a dictionary
- Accessing dictionary values
- Adding new key-value pairs
- Updating existing values
- keys()
- values()
- items()

### 3. Set
- Creating sets
- Understanding duplicate removal
- Understanding why sets do not support indexing
- Union
- Intersection

### 4. Conditional Statements
A Performance Category Program was created using:

- if
- elif
- else

The program accepts a score between 0 and 10 and classifies the performance as:

- Above Average: Score greater than 7
- Average: Score between 4 and 7
- Below Average: Score less than 4
